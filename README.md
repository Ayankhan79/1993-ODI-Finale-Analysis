# 1993 ODI Finale Batting Analysis
# India VS West Indies



## Problem Statement

This dashboard was created to analyze batting performances in the final ODI match between India and West Indies, held on June 25. It helps viewers compare players’ contributions in terms of runs, balls faced, strike rate, boundaries (4s and 6s), and lets users filter for individual players to view their detailed stats. As this is my first Power BI project, the dashboard focuses on presenting essential cricket batting metrics in an easy-to-understand format.

### Steps followed 

Step 1: Loaded the batting summary CSV data into Power BI Desktop.

Step 2: Checked data quality with Power Query (column profiling for errors, blanks).

Step 3: Made sure all columns (player name, runs, balls faced, strike rate, 4s, 6s) had valid values, with minimal or no missing data.

Step 4: Created a new calculated column for “Total Boundaries,” which adds 4s and 6s for each player.

Step 5: In Report view, applied a simple Power BI theme for visual clarity.

Step 6: Added core visuals:

Card visuals for total runs, balls, strike rate, and boundaries.

Bar chart for runs scored by each player.

Slicer (player drop-down) to filter visuals for a selected player.

Step 7: Added player images for visual appeal and easy identification.

Step 8: Inserted text boxes for dashboard title and subheading.

Step 9: Published the report to Power BI Service for sharing.
